# Kompass – Veröffentlichungen

Nur die fertigen Installationspakete von Kompass (einfache Verwaltung für OPNsense) und `latest.json`
mit Version und SHA256-Prüfsumme. Kompass → Mehr → Update liest `latest.json`, lädt das Paket,
prüft die Prüfsumme und installiert es. Keine Zugangsdaten, keine Konfigurationen, kein Quellcode-Verlauf.
